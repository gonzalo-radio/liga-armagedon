# Project preferences

## Git
- Never commit or push without explicit user permission.
- Never add a `Co-Authored-By: Claude` (or any Claude/Anthropic co-author) trailer to git commit messages.

## Warmaster / Public content

- Todo el lore secreto (Vorago, Varn, Protocolo de Resellado, Test de Vorago, elección de bando, etc.) pertenece exclusivamente a `warmaster/`.
- `docs/` es público y no debe contener ninguna referencia a esos conceptos. El Warmaster revela la narrativa en mesa. Los archivos de `docs/` no usan numeración (Introducción, La Campaña, Dominatus, etc.).
- Las release notes en `docs/release-notes.md` deben censurar (`[CENSURADO]`) cualquier entrada que mencione contenido Warmaster.
